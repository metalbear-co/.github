## MetalBear 🐻⚡  
Building tools that make cloud-native development smoother, faster, and more efficient.  

### What We Do  
We're the team behind [mirrord](https://metalbear.com/mirrord?utm_campaign=github-profile&utm_source=github&utm_medium=readme&utm_term=intro) – an open-source tool that lets you run local processes in the cloud, making development on Kubernetes seamless. No unnecessary deployments, no waiting on CI, just code and go.
